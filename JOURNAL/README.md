# Development Journal Rules

The journal preserves detailed implementation history without bloating active Codex context files.

## When To Journal

Append a journal entry when a major implementation slice, deployment, bug, regression, rollback, hotfix, or smoke validation happens.

## File Naming

Use `YYYY-MM-DD.md`.

If multiple sessions occur on the same day, append to the same file.

## Token Rule

Codex should not read journal files during normal work unless historical implementation context is required.
