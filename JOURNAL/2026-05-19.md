## School Day Schedule Reflow

- Improved School Day placement so flexible/non-class course work reflows around fixed classes.
- Added look-ahead behavior that fills usable windows before later fixed classes with a shorter flexible course when the next ordered course is too long.
- Fixed the anchor ordering regression where a fixed class starting at the current cursor could be skipped and an overlapping Flex Block could be generated.
- Validated the behavior against Dexter Mitchell's live School Day workflow during real usage QA.

## Fixed-Class Conflict Protection

- Added frontend class-time conflict detection by student, overlapping weekdays, effective quarter scope, and class time window.
- The Class form now warns in the Students dropdown when a selected student has a conflicting fixed class.
- Class save is blocked with a clear conflict message before roster changes are applied.
- Added backend validation so section-enrollment create/update and course-section schedule edits reject conflicting fixed classes.
- Backend conflict response uses `409` and direct API paths now have the same protection as the UI.
